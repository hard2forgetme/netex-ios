# Notice

Netex iOS is an unofficial iOS companion to [Netex](https://github.com/mrdoob/netex) by Mr.doob.

It is kept in a separate repository so the Android and iOS versions can evolve independently. The goal is to preserve the spirit of Netex on iPhone: a compact web surface with built-in Console, Source, Network, and Three.js inspection panels.
